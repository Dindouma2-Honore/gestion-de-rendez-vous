
# Gestion de Rendez-vous - Clinique

## Description du projet
Application Java de gestion de rendez-vous pour une clinique médicale.
Développée dans le cadre d'un projet de groupe avec NetBeans.

## Fonctionnalités
- Gestion des patients (ajout, modification, suppression)
- Gestion des médecins et leurs spécialités
- Prise de rendez-vous
- Calendrier des consultations
- Dashboard de navigation

## Technologies utilisées
- Java (Swing / JFrame)
- NetBeans IDE
- Git / GitHub
- MySQL (ou SQLite en local)

## Installation
1. Cloner le dépôt : `git clone https://github.com/Dindouma2-Honore/gestion-de-rendez-vous.git`
2. Ouvrir le projet dans NetBeans
3. Exécuter le script SQL pour créer la base de données
4. Configurer DatabaseConfig.java avec vos identifiants locaux
5. Lancer Dashboard.java
